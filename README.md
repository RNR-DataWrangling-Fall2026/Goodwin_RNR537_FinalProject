# Goodwin_RNR537_FinalProject

## Summary

This repository is for my final project in RNR537 Fall 2026 which includes code for analyzing single-species occupancy in Guadalupe Canyon, Arizona/New Mexico.

## Dataset

Animal habitat use data will include camera trap data from Guadalupe Canyon, Arizona and New Mexico that was collected between 2020 and 2025. A total of 40 camera sites were spaced approximately 2.5 km apart and intentionally placed in riparian and upland vegetation communities. The study site covers an area of approximately 25,600 acres and spans land managed by the Bureau of Land Management, U.S. Forest Service, and private ownership. Environmental covariates that will be included in this occupancy model include seasonal vegetation productivity, riparian patch count, and topographic characteristics such as slope, aspect, and terrain ruggedness.

## Structure

Current structure includes folders for code, functions, data_raw, data_clean, and plots.
